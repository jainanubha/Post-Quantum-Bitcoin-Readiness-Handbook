# 9.13 Open research problems

The standardized algorithms establish a foundation for further work. The following questions are deliberately left open: answering them requires security analysis, protocol design, measurements or community review beyond the scope of this introductory iteration.

| Research question | Evidence needed |
| --- | --- |
| Which security categories are appropriate for long-lived UTXOs? | Threat models, multi-target analysis and lifetime assumptions |
| Should Bitcoin support more than one cryptographic assumption? | Failure scenarios, composition analysis and resource trade-offs |
| Can limited-use hash-based signatures work safely in a UTXO wallet? | Signing bounds, transaction replacement and backup models |
| Can PQ threshold signing support distributed custody? | Security proofs, participant assumptions and implementation evidence |
| Can PQ signature aggregation reduce on-chain overhead? | Scheme-specific constructions and measured verification costs |
| What hybrid spending policies are appropriate during transition? | Composition security and migration analysis |
| How can consensus verification costs be bounded? | Exact encodings, adversarial test cases and resource measurements |
| How can future algorithm changes be supported? | Upgrade mechanisms and wallet migration strategies |
| How can signing implementations withstand side channels and faults? | Audits, threat models and reproducible evaluations |
| How should new cryptanalysis influence long-term readiness? | Dated evidence, risk assessment and response plans |

## Exercises and discussion questions

1. Explain why a module-lattice KEM cannot replace a transaction signature, even though both involve public and private keys.
2. Compare the NIST Category 1 reference problem with the classical security characterization of secp256k1. Why are they not interchangeable?
3. Using the tables in sections 9.7 and 9.9, calculate the ratio of ML-DSA-44 and SLH-DSA-SHA2-128s signature lengths to a 64-byte Schnorr signature. Explain why the ratios do not directly predict transaction fees.
4. Give two scenarios in which a wallet might generate more than one signature for the same UTXO.
5. Identify what additional evidence would be necessary before a finalized NIST signature could be proposed as a Bitcoin consensus primitive.
