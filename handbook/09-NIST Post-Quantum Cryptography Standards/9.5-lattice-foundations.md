# 9.5 Mathematical foundations of lattice-based cryptography

## Lattices and hard problems

A lattice is a discrete additive subgroup of a real vector space generated by integer combinations of linearly independent basis vectors $b_1,\ldots,b_n$. Its representation is not unique: different bases can generate the same lattice.

$$
\mathcal L(B)=\left\{\sum_{i=1}^{n}z_i b_i : z_i\in\mathbb Z\right\}.
$$

Two important computational problems are the Shortest Vector Problem (SVP), which asks for a shortest nonzero lattice vector, and the Closest Vector Problem (CVP), which asks for a lattice point closest to a target. Cryptographic constructions generally rely on carefully specified variants or related problems, not on the claim that every lattice problem is difficult.

## Learning With Errors

In the Learning With Errors (LWE) problem, an observer receives modular linear equations containing small unknown errors. An illustrative sample is

$$
b=\langle a,s\rangle+e\pmod q,
$$

where $a$ is a public vector, $s$ is a secret vector, $e$ is sampled from an error distribution and $q$ is a modulus. Without the error term, sufficiently many independent equations could be solved using linear algebra. The errors obscure this relationship. Search-LWE concerns recovering the secret, while decisional-LWE concerns distinguishing noisy samples from uniform ones.

## Short Integer Solution

The Short Integer Solution (SIS) problem asks for a nonzero short vector $z$ satisfying a modular relation for a given matrix $A$:

$$
Az=0\pmod q.
$$

The shortness bound is essential; finding unrestricted solutions to linear equations is not the intended hard problem. Module variants of LWE and SIS replace ordinary scalar entries with elements of a polynomial ring, giving compact structured representations and efficient operations.

## Structured lattices

ML-KEM and ML-DSA perform polynomial arithmetic in rings of the general form

$$
R_q=\mathbb Z_q[X]/(X^{256}+1).
$$

The two schemes use different moduli and parameter sets. The module rank determines the dimensions of vectors and matrices over the ring. Number theoretic transforms (NTTs) accelerate polynomial multiplication using modular arithmetic. These implementation techniques are distinct from the security assumptions themselves.

Falcon instead uses an NTRU lattice construction. Its trapdoor enables a signer to sample appropriately short vectors while an adversary lacking the trapdoor is not expected to do so efficiently.

## Security interpretation

Lattice reduction and other cryptanalytic techniques inform concrete estimates of attack cost. Worst-case-to-average-case reductions give important theoretical support under specified conditions but do not establish a universal concrete security level for every parameter set. Structured problems, sampling distributions and implementation leakage must also be considered.
