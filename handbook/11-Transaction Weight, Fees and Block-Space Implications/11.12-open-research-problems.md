# 11.12 Open research problems and conclusion

Post-quantum migration presents an interaction between cryptographic security and scarce network resources. This chapter has shown how to translate a precisely specified transaction template into byte size, weight, virtual size, fee scenarios and weight-constrained capacity.

## Key takeaways

- Raw signature ratios are not transaction-size or fee ratios; public keys, proofs, encodings and non-signature fields matter.
- Witness data is discounted in weight but still consumes bandwidth and storage. Weight does not bound every verification resource by itself.
- Larger per-input authorization costs amplify the importance of coin selection and batching. The economics of small UTXOs may change substantially.
- A migration transaction usually spends the old output under the old rules. Its size must be distinguished from a future PQ spend.
- Fixed-fee-rate analysis and homogeneous block-capacity estimates are useful controlled scenarios, not network forecasts.
- A real proposal requires exact consensus rules, implementation measurements, wallet lifecycle analysis and a credible migration model.

## Research agenda

| Question | Evidence needed | Priority |
| --- | --- | --- |
| What is the exact transaction encoding of each proposed PQ spending path? | Versioned specifications, test vectors and serialization diagrams or descriptions | High |
| How should verification resources be accounted for? | Worst-case CPU, memory, malformed-input and cross-platform measurements | High |
| How many vulnerable UTXOs must migrate? | Dated UTXO inventory, exposure classification and ownership assumptions | High |
| Which outputs become uneconomical to spend? | Value distributions, spending templates and fee-rate scenarios | High |
| Can aggregation or compact proofs reduce signature overhead? | Concrete constructions, soundness assumptions, metadata and verification costs | High |
| How does migration affect ordinary block-space demand? | Adoption model, miner/fee-market assumptions and sensitivity analysis | High |
| How can wallets optimize coin selection while protecting privacy? | Wallet simulations and privacy analysis | Medium |
| Should weight accounting change for expensive PQ verification? | Resource-cost measurements and consensus design review | High |
