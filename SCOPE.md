# Project Scope

## Goal

The goal of this project is to build an open-source handbook and developer labs for studying post-quantum Bitcoin readiness.

## In scope

- Bitcoin cryptography background
- Quantum-risk model for Bitcoin
- Public-key exposure across output types
- NIST PQC standards
- PQ signature tradeoffs
- BIP360: P2MR
- BIP361 migration debates
- Bitcoin-dev and Delving Bitcoin discussions
- Academic papers
- Developer labs and simulations
- Wallet and exchange readiness checklists

## Out of scope for now

- Proposing a new Bitcoin consensus change
- Endorsing one PQ signature scheme as final
- Making predictions that Bitcoin will be broken by a specific year
- Implementing cryptographic code
